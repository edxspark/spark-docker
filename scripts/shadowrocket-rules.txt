# Shadowrocket 分流规则（粘贴到「规则」里用）
#
# 目的：YouTube 走代理、国内服务全部直连。
# 这样下载照常能下，而 DeepSeek / 阿里云 / 抖音不再绕道海外——
# 抖音也就不会看到海外 IP（这是发布被风控的根源）。
#
# 本机实测的「不分流」代价（ZoogVPN 全局模式）：
#   出口 IP 5.180.77.160（日本东京）
#   阿里云 connect 0.73s、抖音 connect 0.89s、百度直接超时
#   → 国内站点建连应该在 0.01~0.08s，差一个数量级
#
# 加完规则后用 ./scripts/check_network.sh 验证：国内站点建连应该掉到 0.1s 以内。
#
# 顺序有讲究：Shadowrocket 自上而下匹配，命中即停。
# 因此「国内直连」写在前面，「其余走代理」放最后。
